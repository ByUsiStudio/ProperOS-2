# 11 · 系统应用的真实实现与真终端

本文记录 2.5 的一次重要修正：把系统应用从「界面样例」改成「真正在操作这台机器」，
并补上真正的终端。

## 0. 应用格式：从 .jspk 改为 .ppkg

25.0.0 起应用不再以 `.jspk` 单文件分发，改走系统包管理器 `ppkg`：

```
apps/<名字>/                 # 应用源码（manifest.json + ui/*.json）
   │  ppkg-app.py build            # tools/ppkg-app.py
   ▼
<名字>.ppkg                  # PKGINFO + FILES + payload/
   │  ppkg install
   ▼
/opt/properos/apps/<名字>/   # 应用本体（manifest.json + ui/）
/usr/share/applications/properos-<名字>.desktop
```

* 构建：`python3 tools/ppkg-app.py build apps/clock build/clock.ppkg`，
  `make -C src apps` 会产出全部单包与合集包 `properos-apps-25.0.0.ppkg`。
* 校验：`FILES` 是逐文件 SHA-256 清单，`ppkg verify` 全量比对；带 `--key` 时
  额外生成 `SIGNATURE`（`openssl dgst -sha256 -sign`）。
* 安装：payload 直接铺到 `/`，因此「装应用」和「装系统组件」是同一条路径，
  卸载也走同一份数据库。
* 运行时：`load_package()` 同时接受目录与 ZIP，`properos-app /opt/properos/apps/clock`
  可直接跑目录（开发时不必每次打包）。旧 `.jspk` 只保留读取兼容。
* 桌面入口由包内 `.desktop` 提供，`Exec=/usr/bin/properos-app /opt/properos/apps/<名字>`，
  所以 Plasma 的应用抽屉与 framebuffer 兜底桌面看到的是同一批应用。

## 2. 结构

```
                    ┌──────────────────────────────┐
   ui/*.json  ────► │  jspk 运行时（渲染/触摸/动作）│
                    └───────┬──────────────┬───────┘
                            │              │
             "src": "fs.dir"│              │"t": "term"
                            ▼              ▼
                    ┌──────────────┐  ┌──────────────┐
                    │ native.c     │  │ term.c       │
                    │ 数据源/动作  │  │ PTY + VT100  │
                    └──────┬───────┘  └──────┬───────┘
                           │                 │
        opendir/stat、/sys、/proc、statvfs、   openpty + fork +
        ppkg 数据库、V4L2、mmcli、nmcli、      exec bash -l
        pacat/paplay、pactl/wpctl
```

`native.c` 与 `term.c` 都是 C，编进 `properos-app` 本体，不引入解释器，也不需要额外的守护进程。

## 3. 数据源

界面控件写 `"src"`，运行时现场求值：

```json
{ "t": "rows", "src": "fs.dir", "arg": "{{cwd}}", "rowh": 62, "empty": "空目录" }
```

| 数据源 | 参数 | 来源 |
|---|---|---|
| `fs.dir` | 目录 | `opendir` + `lstat`：名称、类型、大小、修改时间；目录优先排序 |
| `fs.places` | — | 主目录/文档/下载/图片/音乐等真实存在的位置 + 各自 `statvfs` |
| `media.tracks` | 目录（可空） | 扫描 `/data/home/Music`、`Downloads`、`/usr/share/sounds`；WAV 解析头部得到时长 |
| `pkg.apps` | — | `/usr/share/properos/apps/*.jspk`、`/data/apps/*`，点击即 `properos-app <包>` |
| `pkg.installed` | — | `/data/apps/<id>/manifest.json` 的 name/version |
| `pkg.db` | — | `/var/lib/ppkg/db/*/PKGINFO`（ppkg 与 deb→ppkg 都在这里） |
| `pkg.local` | — | `Downloads` 下的 `*.deb` / `*.ppkg`，点击走转换安装 |
| `net.ifaces` | — | `getifaddrs` + `/sys/class/net/*`（IPv4、无线标记、operstate、MAC） |
| `modems` | — | `mmcli -L`；没有就返回 0，界面显示「未检测到调制解调器」 |
| `sms.threads` | — | `/data/phone/sms/*.log` 最后一行做摘要 |
| `sms.messages` | 号码 | 该号码的会话文件 |
| `calls` | — | `/data/phone/calls.log`（真实拨号尝试产生） |
| `camera.devices` | — | `VIDIOC_QUERYCAP` 探测 `/dev/video0..7`，只列真正支持 capture 的节点 |
| `sys.info` | — | `/proc`、`/sys`、`statvfs` 组装出的设备/内核/CPU/内存/分区/运行时间/温度/电池/网络 |
| `clock.world` | — | 用 `/usr/share/zoneinfo` 与 `TZ` 计算四地当前时间 |
| `clock.alarms` | — | `/data/home/.config/properos/alarms.conf` |

结果按 `(src, arg)` 缓存 1.2 秒：一帧里测量和绘制会各取一次，避免重复扫目录；任何动作执行后立即失效。

## 4. 动作

```json
{ "type": "native", "op": "fs.up" }
{ "type": "native", "op": "clock.add", "arg": "{{newalarm}}" }
```

| 动作 | 真实行为 |
|---|---|
| `fs.open` | 目录→进入（设置 `cwd` 并压入浏览页）；文本→读进预览（4 KB，按 UTF-8 边界截断）；音频→播放 |
| `fs.up` / `fs.mkdir` / `fs.rm` | 真实路径操作，失败原样返回 `errno` 文案 |
| `media.play` / `media.stop` | 解析 WAV 头，把 data 段接进 `pacat --raw` 的 stdin；180 ms 后检查子进程是否存活，音频服务没起来就报「播放失败：Connection refused」，不会谎称正在播放 |
| `pkg.install` | `.deb` 先 `deb2ppkg` 转成 `*.ppkg`，再 `ppkg install`（内核包由 ppkg 侧拒绝） |
| `pkg.launch` | `fork` 出 `properos-app <包>`，在 Plasma 里是新的 Wayland 窗口 |
| `phone.dial` | 有 modem 走 `mmcli --voice-create-call`；没有则写一条「未拨出：无调制解调器」的通话记录 |
| `sms.send` | 写入本机会话文件；有 modem 才交给 `mmcli --messaging-create-sms`，否则提示「未发出」 |
| `camera.snap` | V4L2：`S_FMT(YUYV)` → `REQBUFS`/`mmap` → `STREAMON` → 取一帧 → YUV 转 RGB → 写 PPM |
| `sys.brightness` / `sys.volume` | 写 `/sys/class/backlight/*/brightness`；`wpctl set-volume` 或 `pactl set-sink-volume` |
| `wifi on/off` | `nmcli radio wifi on/off` |
| `clock.add` / `clock.toggle` | 真实读写闹钟表并翻转开关 |
| `pkg.remove` / `app.remove` | `ppkg remove` / `papp remove`（需要 root，会如实报权限不足） |

危险操作不放进界面：`pkg.db` 只读展示，卸载系统包仍走命令行，避免误触。

## 5. 真终端

### 5.1 伪终端

```c
master = posix_openpt(O_RDWR | O_NOCTTY);
grantpt/unlockpt;
pid = fork();
/* 子进程 */ setsid(); open(ptsname); ioctl(TIOCSCTTY);
             dup2(slave, 0/1/2); setenv("TERM", "xterm-256color");
             execl("/bin/bash", "bash", "-l", NULL);   /* 没有 bash 用 /bin/sh */
```

master 端设 `O_NONBLOCK`，主循环每帧 `read` 到 `EAGAIN` 为止，解析进网格。
窗口尺寸变化时 `ioctl(TIOCSWINSZ)` 并 `SIGWINCH`，`vim`、`top`、`less` 会跟着重排。

### 5.2 解析范围

- C0：`\b \t \n \r \a`（响铃忽略）
- CSI：`m`（SGR：1/2/4/7/22/24/27、30–37、40–47、90–97、100–107、38/48 的 `;5;n` 与 `;2;r;g;b`）
- 光标与擦除：`A B C D E F G H f d J K L M P @ X S T r s u`
- 模式：`?25`（光标显隐）、`?1049/47`（备用屏按清屏处理）、`?2004`（忽略）
- ESC：`( ) * +` 字符集（忽略）、`7 8 D E M c`
- OSC：`ESC ] ... BEL/ST` 整段丢弃（改标题不显示）
- UTF-8 增量解码，非法序列记 `U+FFFD`

未实现的序列按规范忽略，不会把控制字符打进屏幕。

### 5.3 网格与渲染

- 1000 行历史；全屏滚动时优先推进 `hist_top`，到顶才 `memmove` 丢最老一行
- 东亚宽度按 2 格（CJK、假名、韩文、全角标点、emoji 区），其余 1 格
- 字体图集不是等宽字体，所以单元格宽度取 `"0123456789"` 的平均宽 +1 px，字符左对齐，视觉上接近等宽终端
- 背景色按单元格填，前景按 SGR 解析出的 RGB 绘制；粗体用 1 px 偏移叠画，暗色用混合
- 回看时右上角显示「回看 N 行」，`PgUp/PgDn` 翻页，输入或回到 0 行自动回底

### 5.4 键盘

触摸键盘 6 行：

```
Esc  Tab  Ctrl  ↑  ↓  ←  →  PgUp  PgDn  Del
1 2 3 4 5 6 7 8 9 0
q w e r t y u i o p
a s d f g h j k l '
z x c v b n m            Shift
123        空格              回车
```

`Ctrl` 是粘滞修饰键：按一次变蓝，下一个字母转成 `0x01–0x1A`；`123` 切换到符号页。
实体键盘（evdev `IN_KEY`）直接转发：方向键转 `ESC [ A/B/C/D`，退格 `0x7F`，回车 `\r`。

## 6. 应用对照

| 应用 | 现在做什么 |
|---|---|
| 终端（新增） | 真 bash，可 `ls`、`apt`、`vim`、`top`；输出颜色与中文正常 |
| 文件 | 真实目录浏览与容量；点文本进预览页，点音频直接播，可建目录 |
| 音乐 | 扫描真实音频文件并显示时长；播放/停止是真实 PCM 进程 |
| 商店 | 三个真实列表：papp 应用、.jspk 系统应用、本地 deb/ppkg；点击安装 |
| 设置 | 电池/内存/网络/分区全部实时；亮度滑杆写 backlight，音量写 PipeWire/PulseAudio |
| 时钟 | 时间与四地时区真实；闹钟表可增可开关；秒表真实计时 |
| 电话 | modem 列表来自 ModemManager；拨号失败会留下带原因的通话记录 |
| 消息 | 会话来自本机会话文件；无 modem 时明确标注未发出 |
| 相机 | 只列真正可采集的 V4L2 节点；拍照真的取帧存 PPM，无设备就如实报错 |
| 欢迎 | 设备型号、内核、CPU、内存、分区都是本机读数 |

## 7. 怎么验证

```bash
# 离屏渲染一页（不依赖显示器）
properos-app /usr/share/properos/apps/files.jspk --render 720x1280 /tmp/f.bmp 1

# 终端：启动真 shell 并把前 6 行打到 stderr
PROPEROS_TERM_FOCUS=1 PROPEROS_TERM_DUMP=1 \
  properos-app /usr/share/properos/apps/terminal.jspk --render 720x1280 /tmp/t.bmp 1
```

第二条第 0 行应出现 `root@properos:~#`。`PROPEROS_TERM_FOCUS=1` 只是让离屏渲染也画上键盘，方便检查布局。

## 8. 已知限制

- 音频只保证 WAV（本机解析 PCM）。mp3/flac/ogg 交给 `paplay`，缺解码器时会报错而不是静默。
- 相机只有 YUYV 单帧抓拍，没有取景预览与录像；PPM 可直接用文件应用看到大小，转 JPEG 需要额外编码器。
- 没有 modem 的机器上，电话与短信只能记录本地事实，不能收发。
- 闹钟表可读写，但响铃依赖应用在前台；后台响铃需要独立服务，尚未实现。
