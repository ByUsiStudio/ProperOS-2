# ProperOS 2.5 构建、安装与使用手册

面向 ARM64 手机/UEFI 设备。所有命令都在仓库根目录执行。

## 1. 产物与目录

```text
properos-2.5/
├── build/
│   ├── 00-env.sh                版本、镜像源、工作目录
│   └── arch/arm64/
│       ├── 10-kernel.sh         交叉编译 Linux 7.3.6（全内建，无模块）
│       ├── 20-rootfs.sh         debootstrap arm64 + 组件 + overlay + 内核注入
│       ├── 30-initramfs.sh      busybox + ProLoader 作为 /init
│       ├── 40-image.sh          GPT 三分区磁盘镜像（无需 loop）
│       └── 50-iso.sh            live squashfs + EFI 镜像 + El Torito ISO
├── src/                         原生 C 组件（见 docs/05）
├── installer/
│   ├── init                     live initramfs 的 /init
│   ├── install.sh               properos-install（whiptail 向导）
│   ├── tty-console.sh           16x32 控制台字体
│   └── properos-live-installer.service
├── overlay/                     系统根叠加层（systemd 单元、配置、EFI 引导器）
├── tools/
│   ├── gen_font.py              烘焙 CJK 点阵字库
│   └── package-source.sh        打源码 zip
├── docs/                        架构、构建、验证、移植
└── dist/                        产物（构建后生成）
    ├── ProperOS-2.5-arm64.iso
    ├── ProperOS-2.5-arm64.img
    ├── ProperOS-2.5-source.zip
    └── kernel/{Image-properos-2.5, config-2.5.0-properos-arm64}
```

## 2. 构建环境

| 项 | 要求 |
|---|---|
| 宿主 | Ubuntu 22.04+ / Debian 12+，x86_64 |
| 权限 | root（debootstrap、mknod、挂载） |
| 磁盘 | ≥ 12 GiB（内核源码 2 GiB + rootfs 1.2 GiB + 镜像 4.1 GiB） |
| 内存 | ≥ 4 GiB（`make -j5` 编内核） |
| 网络 | 需访问 Debian 源与 kernel.org 镜像 |

```bash
sudo apt install -y \
    build-essential bc bison flex libssl-dev libelf-dev \
    gcc-aarch64-linux-gnu binutils-aarch64-linux-gnu \
    qemu-user-static debootstrap \
    mtools dosfstools e2fsprogs gdisk parted xorriso squashfs-tools \
    grub-efi-arm64-bin
```

`qemu-user-static` 必须注册 binfmt_misc，否则 debootstrap 第二阶段的
`aarch64` 程序无法在 x86 宿主上执行：

```bash
ls /proc/sys/fs/binfmt_misc/ | grep aarch64   # 应出现 qemu-aarch64
```

## 3. 构建

```bash
# 五步，全部可重复执行（已完成的步骤会复用工作目录）
sudo bash build/arch/arm64/10-kernel.sh     # 约 8-15 分钟（5 核）
sudo bash build/arch/arm64/20-rootfs.sh     # 约 3-6 分钟（debootstrap + 包安装）
sudo bash build/arch/arm64/30-initramfs.sh  # 约 5 秒
sudo bash build/arch/arm64/50-iso.sh        # 约 2 分钟（xz 压缩 squashfs）
sudo bash build/arch/arm64/40-image.sh      # 约 3 分钟（写 4.1 GiB 镜像）

bash tools/package-source.sh                # 源码 zip
```

工作目录在 `build/00-env.sh` 里定义（默认 `/root/build`），
产物统一落在 `dist/`。

内核配置改动后只重跑 `10-kernel.sh` + `50-iso.sh` 即可，
`20-rootfs.sh` 会把 `dist/kernel/Image-properos-2.5` 复制进 rootfs。

## 4. 烧写

```bash
# 安装 ISO（推荐：可自选磁盘、可留空 root 密码）
sudo dd if=dist/ProperOS-2.5-arm64.iso of=/dev/sdX bs=4M status=progress oflag=sync

# 预装镜像（已经装好，开机即用）
sudo dd if=dist/ProperOS-2.5-arm64.img of=/dev/sdX bs=4M status=progress oflag=sync

sha256sum -c dist/ProperOS-2.5-arm64.iso.sha256
```

设备必须有 UEFI 固件（`/EFI/BOOT/BOOTAA64.EFI`）。手机通常需要先解锁
bootloader，具体见 `docs/06-ARM64设备移植.md`。

## 5. 安装向导

从 ISO 启动后 10 秒自动进入（也可在 GRUB 里选第一项）。界面是 Debian
Installer 风格：蓝底、灰框、红色标题，80x25 栅格。

1. **Welcome** — 说明这一屏在做什么
2. **Partition disks** — 列出所有可安装整盘（已过滤 loop / nbd / 容量为 0 的设备）
3. **Hostname** — 默认 `properos`
4. **Root password** — 可留空。留空时二次确认，装完不设密码、tty1 自动登录 root
5. **Ready to install** — 汇总设备/架构/主机名/密码/分区方案
6. **Confirm** — 最后一次破坏性确认
7. **Installing the system** — 进度条（分区 → 格式化 → 挂载 → 拷贝 → 配置 → 引导 → 同步）
8. **Finished** — 可移除介质并重启

分区方案（GPT）：

| 分区 | 大小 | 类型 | 挂载 |
|---|---|---|---|
| `properos-esp` | 256 MiB | FAT32 | `/boot/efi` |
| `properos-system` | 3–4 GiB | ext4 | `/`（只读） |
| `properos-data` | 剩余 | ext4 | `/data`（可写层 + 应用） |

### 无人值守

```bash
properos-install --disk /dev/mmcblk0 --yes --blank-password
properos-install --disk /dev/mmcblk0 --yes --password 'ChangeMe_2026' --hostname lab-01
```

或走内核参数（GRUB 第三项就是这个）：

```text
properos.autoinstall=/dev/vda properos.blankpass=1
```

| 参数 | 说明 |
|---|---|
| `--disk DEV` | 目标整盘；给出即进入无人值守 |
| `--password PASS` | root 密码；省略则留空 |
| `--blank-password` | 显式留空（不设密码 + tty1 自动登录） |
| `--hostname NAME` | 主机名，默认 `properos` |
| `--yes` / `-y` | 跳过最终确认 |
| `--force` | 连 do_install 的确认对话框也跳过 |

日志：`/var/log/properos-install.log`（live 与目标机都有）。

## 6. 首次启动

```text
UEFI → GRUB → Linux 7.3.6 → initramfs(ProLoader) → StBoot → systemd → 移动端启动器
```

- 默认账户 `root`，安装时留空则无密码、tty1 自动登录
- 图形界面是帧缓冲启动器（tty7），可用方向键/触摸操作
- 文本控制台：`Ctrl+Alt+F1`
- 首启服务会自动 `properos-bootctl mark-good`、建立 `/data/apps`、生成 SSH 主机密钥

常用命令：

```bash
properos-bootctl status        # A/B 槽状态
properos-bootctl mark-good     # 标记本次启动成功
properos-bootctl rollback      # 回滚到另一槽
papp list                      # 已安装应用
ppkg list                      # 已安装系统包
systemctl status properd       # 服务守护进程
```

## 7. QEMU 快速验证

```bash
# 从 ISO 装到一块 12 GiB 空盘
truncate -s 12G /tmp/target.img
qemu-system-aarch64 -M virt -cpu cortex-a72 -m 2048 -smp 2 \
  -drive if=pflash,format=raw,file=/usr/share/AAVMF/AAVMF_CODE.fd,readonly=on \
  -drive if=none,file=dist/ProperOS-2.5-arm64.iso,format=raw,media=cdrom,readonly=on,id=cd0 \
  -device virtio-scsi-device -device scsi-cd,drive=cd0 \
  -drive if=none,file=/tmp/target.img,format=raw,id=hd0 \
  -device virtio-blk-device,drive=hd0 \
  -device virtio-gpu-pci -device virtio-keyboard-pci -device virtio-tablet-pci \
  -vnc 127.0.0.1:0 -boot d
```

要点：

- **必须加 `-device virtio-keyboard-pci`**：ARM `virt` 机器没有 PS/2，
  没有这个设备安装器收不到任何按键。
- 光驱用 `virtio-scsi-device` + `scsi-cd`，`virtio-blk` 挂 ISO 时 UEFI
  不认 El Torito，会直接报 `failed to load Boot0001`。
- `-display none` + monitor `sendkey` 不生效（没有活动控制台），
  要用 `-vnc` 或 `-display gtk`。
- 串口日志：`-serial file:/tmp/serial.log`，或 `-serial unix:/tmp/ser.sock,server,nowait` 交互登录。

## 8. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 固件报 `failed to load Boot0001 Not Found` | ISO 的 efiboot.img 太大，El Torito 16 位扇区计数溢出 | 用仓库脚本重建（EFI 镜像固定 16 MiB FAT16） |
| 安装界面按键无反应 | 虚拟机没挂键盘 | 加 `-device virtio-keyboard-pci` |
| 界面边框是字母或乱码 | 控制台字体不是 CP437 布局 / locale 是 UTF-8 | 装 `kbd`，用 `properos-tty-console` 换 16x32 字体，界面 locale 为 `C` |
| 启动卡在 `dev-disk-by\x2dlabel-...` | 目标机 fstab 与介质不匹配 | 安装器会重写 fstab；手动场景请从只读 squashfs 拷贝系统 |
| `systemctl --failed` 有 `serial-getty@ttyS0` | ARM64 上不该启用 ttyS0 | 安装器已按架构只启用 ttyAMA0 |
| 屏幕一直停在文本，看不到启动器 | 前台 VT 不是 tty7 | `systemctl restart properos-shell`（单元里有 `chvt 7`） |
