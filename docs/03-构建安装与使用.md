# ProperOS 2.5 构建、安装与使用手册

面向 ARM64 手机/UEFI 设备。所有命令都在仓库根目录执行。

## 1. 产物与目录

```text
properos-2.5/
├── build/
│   ├── 00-env.sh                版本、镜像源、工作目录
│   └── arch/arm64/
│       ├── 10-kernel.sh         交叉编译 Linux 7.3.6（全内建，无模块）
│       ├── 20-rootfs.sh         debootstrap arm64 + 组件 + overlay + 内核注入
│       ├── 30-initramfs.sh      busybox + ProLoader 作为 /init
│       ├── 40-image.sh          GPT 三分区磁盘镜像（无需 loop）
│       └── 50-iso.sh            live squashfs + EFI 镜像 + El Torito ISO
├── src/                         原生 C 组件
│   ├── gfx/                     帧缓冲绘制、控件、evdev 输入
│   ├── shell/                   桌面（Plasma Mobile 形态）
│   ├── ui/                      图形安装器
│   ├── jspk/                    .jspk 应用运行时（ZIP + DEFLATE + JSON + UI）
│   ├── papp/ ppkg/ properd/     应用沙箱、系统包、服务守护

├── tools/
│   ├── gen_font.py              烘焙 CJK 点阵字库

├── docs/                        架构、构建、验证、移植
```

## 2. 构建环境

| 项 | 要求 |
|---|---|
| 宿主 | Ubuntu 22.04+ / Debian 12+，x86_64 |
| 权限 | root（debootstrap、mknod、挂载） |
| 磁盘 | ≥ 12 GiB（内核源码 2 GiB + rootfs 1.2 GiB + 镜像 4.1 GiB） |
| 内存 | ≥ 4 GiB（`make -j5` 编内核） |
| 网络 | 需访问 Debian 源与 kernel.org 镜像 |

```bash
sudo apt install -y \
    build-essential bc bison flex libssl-dev libelf-dev \
    gcc-aarch64-linux-gnu binutils-aarch64-linux-gnu \
    qemu-user-static debootstrap \
    mtools dosfstools e2fsprogs gdisk parted xorriso squashfs-tools \
    grub-efi-arm64-bin
```

`qemu-user-static` 必须注册 binfmt_misc，否则 debootstrap 第二阶段的
`aarch64` 程序无法在 x86 宿主上执行：

```bash
ls /proc/sys/fs/binfmt_misc/ | grep aarch64   # 应出现 qemu-aarch64
```

## 3. 构建

```bash
# 五步，全部可重复执行（已完成的步骤会复用工作目录）
sudo bash build/arch/arm64/10-kernel.sh     # 约 8-15 分钟（5 核）
sudo bash build/arch/arm64/20-rootfs.sh     # 约 3-6 分钟，内部会 make 组件 + 安装应用
sudo bash build/arch/arm64/30-initramfs.sh  # 约 5 秒
sudo bash build/arch/arm64/50-iso.sh        # 约 2 分钟（xz 压缩 squashfs）
sudo bash build/arch/arm64/40-image.sh      # 约 3 分钟（写 4.1 GiB 镜像）

bash tools/package-source.sh                # 源码 zip
```

`20-rootfs.sh` 里已经包含 `make -C src ARCH=arm64` 与 `make install`，
所以 `.jspk` 应用会被自动打包并装进 `/usr/share/properos/apps/`，
不需要单独执行安装步骤。

工作目录在 `build/00-env.sh` 里定义（默认 `/root/build`），
产物统一落在 `dist/`。

### 只改 C 组件时

```bash
cd src
make ARCH=arm64                            # 只重编组件
make ARCH=arm64 install DESTDIR=/root/build/rootfs-arm64
cd .. && bash build/arch/arm64/40-image.sh # 只重打镜像，约 3 分钟
```

`40-image.sh` 直接从 `$ROOT`（rootfs 工作目录）组装镜像，
不会重新 debootstrap，所以改完代码 3 分钟就能出可启动镜像。

### 只改系统应用时

```bash
python3 tools/jspk-pack.py --all           # 校验 + 打包 apps/* → build/apps/
make -C src ARCH=arm64 install DESTDIR=/root/build/rootfs-arm64
```

`jspk-pack.py` 会先做静态校验：manifest 必填字段、`entry` 文件存在、
`start` 页面存在、所有 `to`/`back` 目标页面存在、动作类型合法。
任何一条不满足都直接报错并指出文件名与位置，不会打出坏包。

## 4. 烧写

```bash
# 安装 ISO（推荐：可自选磁盘、可留空 root 密码）
sudo dd if=dist/ProperOS-2.5-arm64.iso of=/dev/sdX bs=4M status=progress oflag=sync

# 预装镜像（已经装好，开机即用）
sudo dd if=dist/ProperOS-2.5-arm64.img of=/dev/sdX bs=4M status=progress oflag=sync

sha256sum -c dist/ProperOS-2.5-arm64.iso.sha256
```

设备必须有 UEFI 固件（`/EFI/BOOT/BOOTAA64.EFI`）。手机通常需要先解锁
bootloader，具体见 `docs/06-ARM64设备移植.md`。

## 5. 安装向导

从 ISO 启动后 10 秒自动进入图形安装器（`properos-setup`，tty1 独占帧缓冲）。
界面是 Ubuntu 安装器风格：深色标题区 + 橙色强调 + 白色圆角卡片，
四步走完，全触摸可操作（左下角有屏幕键盘）。

| 步骤 | 页面 | 内容 |
|---|---|---|
| 1/4 | 欢迎 | 版本、架构、三项特性；`退出` / `开始安装` |
| 2/4 | 安装位置 | 安装类型（整盘清除 / 手动分区）、目标磁盘单选、分区预览条 |
| 3/4 | 账户与设备 | 设备名称（默认 `properos`）、root 密码（可留空）、「不设置 root 密码」勾选框 |
| 4/4 | 确认 | 汇总设备/架构/主机名/密码/分区方案，最后一次破坏性确认 |
| — | 安装中 | 七段进度：分区 → 格式化 → 挂载 → 拷贝 → 配置 → 引导 → 同步 |
| — | 完成 | 提示可移除介质并重启 |

密码留空时系统不设 root 密码，`tty1` 自动登录并直接进桌面；
装完之后也可以在「设置 → 关于 → root 密码」里补设。

分区方案（GPT）：

| 分区 | 大小 | 类型 | 挂载 |
|---|---|---|---|
| `properos-esp` | 256 MiB | FAT32 | `/boot/efi` |
| `properos-system` | 3–4 GiB | ext4 | `/`（只读） |
| `properos-data` | 剩余 | ext4 | `/data`（可写层 + 应用） |

### 无人值守

```bash
properos-install --disk /dev/mmcblk0 --yes --blank-password
properos-install --disk /dev/mmcblk0 --yes --password 'ChangeMe_2026' --hostname lab-01
```

或走内核参数（GRUB 第三项就是这个）：

```text
properos.autoinstall=/dev/vda properos.blankpass=1
```

| 参数 | 说明 |
|---|---|
| `--disk DEV` | 目标整盘；给出即进入无人值守 |
| `--password PASS` | root 密码；省略则留空 |
| `--blank-password` | 显式留空（不设密码 + tty1 自动登录） |
| `--hostname NAME` | 主机名，默认 `properos` |
| `--yes` / `-y` | 跳过最终确认 |
| `--force` | 连 do_install 的确认对话框也跳过 |

日志：`/var/log/properos-install.log`（live 与目标机都有）。

## 6. 首次启动

```text
UEFI → GRUB → Linux 7.3.6 → initramfs(ProLoader) → StBoot → systemd → properos-shell
```

- 默认账户 `root`，安装时留空则无密码、tty1 自动登录
- 桌面跑在 tty7，直接写帧缓冲，触摸 / 鼠标 / 键盘都能操作
- 文本控制台：`Ctrl+Alt+F1`
- 首启服务会自动 `properos-bootctl mark-good`、建立 `/data/apps`、生成 SSH 主机密钥

桌面形态（Plasma Mobile 参考）：

| 区域 | 说明 |
|---|---|
| 顶部状态栏 | 时间、Wi-Fi、电量；右侧下拉区域可拉开快捷设置 |
| 主屏图标网格 | 4 列 × 4 行分页，横向滑动切页，长按弹菜单 |
| 底部 Dock | 5 个常用应用 + 抽屉按钮，常驻可点 |
| 应用抽屉 | 从底部上滑，带搜索框与应用网格，右上关闭 |
| 快捷设置 | 从顶部下拉，亮度/音量滑块 + 8 个磁贴 |
| 手势 | 左右边缘内滑 = 返回；上滑 = 抽屉；下滑 = 快捷设置；长按 = 菜单 |

常用命令：

```bash
properos-bootctl status        # A/B 槽状态
properos-bootctl mark-good     # 标记本次启动成功
properos-bootctl rollback      # 回滚到另一槽
papp list                      # 已安装应用
ppkg list                      # 已安装系统包
properos-jspk /usr/share/properos/apps/clock.jspk   # 直接运行单个应用
systemctl status properd       # 服务守护进程
```

## 7. 系统应用与 .jspk

系统自带 10 个应用，全部以 `.jspk` 交付，装在 `/usr/share/properos/apps/`：

| 应用 | 包名 | 说明 |
|---|---|---|
| 设置 | `miao.byusistudio.settings` | 11 页：root、显示、超时、声音、电池、移动网络、主屏、存储、更新、关于 |
| 文件 | `miao.byusistudio.files` | 存储用量、快捷分类、最近文件、位置 |
| 时钟 | `miao.byusistudio.clock` | 大时钟、世界时钟、闹钟、秒表 |
| 计算器 | `miao.byusistudio.calc` | 四则运算、退格、清空、历史 |
| 电话 | `miao.byusistudio.phone` | 拨号盘、最近通话 |
| 消息 | `miao.byusistudio.message` | 会话列表、未读 |
| 相机 | `miao.byusistudio.camera` | 拍照/录像/切换，无摄像头时显示占位 |
| 音乐 | `miao.byusistudio.music` | 播放器、进度、播放列表 |
| 应用商店 | `miao.byusistudio.store` | 推荐、已安装、系统组件 |
| 欢迎 | `miao.byusistudio.welcome` | 首次使用引导 |

`.jspk` 是 ZIP 容器，内含 `manifest.json` + `ui/*.json` 声明式界面，
由 `properos-jspk` 解释执行，不编译、不需要动态链接库。
完整格式说明见 `docs/09-桌面与jspk应用.md`。

调试一个应用不用开虚拟机：

```bash
src/build/x86_64/properos-jspk build/apps/clock.jspk --render 720x1280 /tmp/clock.bmp
src/build/x86_64/properos-jspk build/apps/clock.jspk --render 720x1280 /tmp/clock.bmp alarm
```

## 8. QEMU 快速验证

```bash
# 从 ISO 装到一块 12 GiB 空盘
truncate -s 12G /tmp/target.img
qemu-system-aarch64 -M virt -cpu cortex-a72 -m 2048 -smp 2 \
  -drive if=pflash,format=raw,file=/usr/share/AAVMF/AAVMF_CODE.fd,readonly=on \
  -drive if=none,file=dist/ProperOS-2.5-arm64.iso,format=raw,media=cdrom,readonly=on,id=cd0 \
  -device virtio-scsi-device -device scsi-cd,drive=cd0 \
  -drive if=none,file=/tmp/target.img,format=raw,id=hd0 \
  -device virtio-blk-device,drive=hd0 \
  -device virtio-gpu-pci -device virtio-keyboard-pci -device virtio-tablet-pci \
  -vnc 127.0.0.1:0 -boot d
```

要点：

- **必须加 `-device virtio-keyboard-pci`**：ARM `virt` 机器没有 PS/2，
  没有这个设备安装器收不到任何按键。
- 光驱用 `virtio-scsi-device` + `scsi-cd`，`virtio-blk` 挂 ISO 时 UEFI
  不认 El Torito，会直接报 `failed to load Boot0001`。
- `-display none` + monitor `sendkey` 不生效（没有活动控制台），
  要用 `-vnc` 或 `-display gtk`。
- 触摸手势要用 QMP 的 `input-send-event` 发连续 `abs` 坐标 + `btn`，
  `input-send-event` 的坐标是 0–32767 归一化值。
- 串口日志：`-serial file:/tmp/serial.log`，或 `-serial unix:/tmp/ser.sock,server,nowait` 交互登录。

## 9. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 固件报 `failed to load Boot0001 Not Found` | ISO 的 efibootimg 太大，El Torito 16 位扇区计数溢出 | 用仓库脚本重建（EFI 镜像固定 16 MiB FAT16） |
| 安装界面按键无反应 | 虚拟机没挂键盘 | 加 `-device virtio-keyboard-pci` |
| 启动卡在 `dev-disk-by\x2dlabel-...` | 目标机 fstab 与介质不匹配 | 安装器会重写 fstab；手动场景请从只读 squashfs 拷贝系统 |
| `systemctl --failed` 有 `serial-getty@ttyS0` | ARM64 上不该启用 ttyS0 | 安装器已按架构只启用 ttyAMA0 |
| 屏幕一直停在文本，看不到桌面 | 前台 VT 不是 tty7 | `systemctl restart properos-shell`（单元里有 `chvt 7`） |
| 桌面图标很小 / 间距挤 | 分辨率与密度基准不符 | 布局按 `min(W,H)/360` 缩放，改分辨率后会自动重算；异常时看 `journalctl -u properos-shell` |
| 应用打开后黑屏 | `.jspk` 缺 `entry` 或 JSON 语法错 | `properos-jspk <包> --render 720x1280 /tmp/a.bmp` 单独跑，错误会打到 stderr |
| 触摸位置偏移 | 触摸屏 `ABS_X/ABS_Y` 的 min/max 与屏幕分辨率不一致 | `properos-shell` 读 evdev 的 absinfo 做归一化；可用 `evtest` 核对 |
